# Learn SecByte EvilBox, Enumeration, Shellshock & Web Shell CTF Labs

Hands-on cybersecurity and CTF lab collection focused on EvilBox, Linux enumeration, hidden files and paths, shell techniques, Shellshock, foothold development, mailbox discovery, hashes, and file-upload security concepts.

These labs are useful for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners practicing authorized security testing.

## Introduction

The collection covers multiple stages of a practical security assessment, from initial enumeration and information discovery to obtaining and stabilizing shells.

The labs also provide focused practice with hidden resources, hash-related investigation, mailbox harvesting, Shellshock, foothold techniques, shell operations, and upload-bypass concepts.

Use these exercises only in authorized training environments.

## Learning Path

A practical progression through this collection is:

1. Start with **Evil Enumeration** to build systematic reconnaissance skills.
2. Continue with **EvilBox System Sweep** for broader system discovery.
3. Practice finding concealed resources with **Hidden Files Hidden Paths** and **Secret Paths Hidden Keys**.
4. Explore **Evil MailBox Harvest** and **Evil HashBox** for information and hash-related investigation.
5. Study **EvilBox Foothold Forge** to understand initial access concepts.
6. Practice shell techniques using **Shell Harbor** and **EvilBox Shellcraft**.
7. Use **ShellStabilizer** to understand shell stabilization.
8. Study **Shellshock to Root** for a deeper exploitation and privilege-escalation scenario.
9. Finish with **Upload Bypass EvilBox One** to examine file-upload security.

## How to Use the Labs

1. Select a lab from the direct-link index.
2. Confirm that the target is part of an authorized lab environment.
3. Read the objectives and understand the intended scope.
4. Perform enumeration before attempting exploitation.
5. Document discovered files, paths, services, application behavior, and other findings.
6. Test techniques only against the permitted target.
7. Record your methodology and evidence.
8. After completing a lab, review possible defensive mitigations.
